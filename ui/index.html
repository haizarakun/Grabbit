            スマホ連携
            
                            無料の通知アプリ「ntfy」を使って、スマホに完了を知らせたり、スマホの共有メニューから PC の Grabbit に URL を送ったりできます。
                            
            
                            
              
              
            
                            
            
                            
              
              
            
                            
            
                            
            
                            
              スマホ側の準備
              
                              
                
                            1. スマホに「ntfy」アプリを入れる(Android / iPhone)
                              2. 
                
                            2. 通知: アプリで「」を購読する
                              3. 
                
                            3. URL を送る: 動画アプリの「共有」→「ntfy」→ トピックに「」を入れて送る
                              4. 
              
                            
              
                            iPhone のショートカットで送る(共有メニューから1回で送れます)
                            
              
                              
                
                            1. 「ショートカット」アプリで新しいショートカットを作り、「共有シートに表示」をオンにして、受け取るものを「URL」にする
                              2. 
                
                            2. 「URL の内容を取得」を足し、URL に  を入れる
                              3. 
                
                            3. 方法を「POST」、本文を「ファイル」にして「ショートカットの入力」を選ぶ
                              4. 
                
                            4. 名前を「Grabbit に送る」にすると、動画アプリの共有メニューから選べます
